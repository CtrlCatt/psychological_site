# «Рядом» — фронтенд на Angular 20 + TypeScript

Лабораторная работа. Интерфейс перенесён из предоставленного экспорта **Figma Make** (`App.tsx`, `index.css`, `site.json`, `favicon.svg`) с React 19 на Angular 20. Исходники проекта лежат в `src/app/`, React и Vite не используются.

## Как запустить

1. Установите **Node.js 22 LTS (22.12+) или 24 LTS** (потребуется доступ к npm в первый раз).
2. Скачайте именно ветку `lab-2` или выполните `git clone --branch lab-2 https://github.com/CtrlCatt/psychological_site.git`, затем `cd psychological_site`.
3. Выполните в терминале:

   ```bash
   npm ci
   npm start
   ```

4. Откройте `http://localhost:4200` (обычно откроется автоматически).

Команда `npm run build` собирает готовую версию в `dist/`. Команда `npm run check` выполняет сборку в режиме разработки.

## Что реализовано

- **Главная страница** — хедер и мобильное меню, блок экспресс-теста, выбор тестов, карточки психологов, описание сервиса, футер.
- **Экспресс-тест** — вопросы по шагам, прогресс, обработка ответов, результат и повторное прохождение.
- **Каталог психологов** — карточки с фотографиями, стоимостью и демонстрационным выбором времени консультации. Это **макет**, реальные слоты не проверяются, запись никуда не отправляется.
- **Личный кабинет** (`/account`) — блоки обзора, четыре опросника (GAD-7, PHQ-9, PSS-10, ISI), модальные окна, прогресс, результаты, история.
- **Сохранение результатов в localStorage** — после нажатия «Сохранить результат» появляется запись в истории. Результаты остаются в браузере до очистки хранилища.
- Адаптивные стили из Figma Make: **Tailwind CSS 4**, Manrope, Playfair Display, SVG-иконки, изображения Unsplash.

## Важно для защиты лабораторной

- Фреймворк: **Angular 20**, язык: **TypeScript**, используются standalone-компоненты, встроенные `@if`, `@for`, `@switch`, Angular Router, события `(click)` и property binding.
- На сайте **нет бэкенда**: данные об аккаунте, записях, графике и специалистах демонстрационные.
- Контент опросников взят из визуального прототипа. Подсчёт баллов **упрощён** и не является валидированной диагностикой, результаты не предназначены для принятия медицинских решений.
- Внешние изображения и Google Fonts требуют интернет-соединения; без него страница работает, но шрифты и фотографии могут не загрузиться.
- Для реальной регистрации, хранения персональных данных, профилей психологов и бронирования нужно подключать серверную часть.

## Проверка сборки

Проверено 22 октября 2026 года на Node.js 24.22.0 и npm 11.19.1:

- `npm ci --no-audit --no-fund` — зависимости установлены из lock-файла.
- `npm run build` — production-сборка успешно создана в `dist/figma-angular20-lab/browser/`.
- `npm run check` — сборка разработки со строгой проверкой шаблонов и TypeScript успешна.
- В браузере проверены экспресс-тест (4 ответа → результат), демонстрация записи (выбор времени → подтверждение), переход в кабинет, GAD-7 (7 ответов → сохранение), сохранность истории после перезагрузки `/account`, возврат на главную. Ошибок JavaScript при этих действиях не обнаружено.

Production-сборка загружает Google Fonts и требует доступа к `fonts.googleapis.com`.

## Как проверить преподавателю

1. Откройте [Files changed в PR №2](https://github.com/CtrlCatt/psychological_site/pull/2/files): теперь там есть `src/main.ts`, компоненты, HTML-шаблоны и сервис хранения.
2. Выполните `npm ci`, `npm run build`, затем `npm run dev` и откройте `http://localhost:4200`.
3. Нажмите «Пройти экспресс-тест», ответьте на четыре вопроса и проверьте результат.
4. Нажмите «Записаться» у психолога: до выбора времени продолжить нельзя; после выбора появляется подтверждение демонстрации.
5. В «Личном кабинете» откройте GAD-7, пройдите семь вопросов, сохраните результат и обновите страницу: запись остаётся в истории.
6. Откройте `/account` напрямую и проверьте возврат на главную.

Скриншоты проверенного приложения: [главная](docs/screens/home.png), [кабинет](docs/screens/account.png).
