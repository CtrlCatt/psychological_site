# Angular 20 — лабораторная №5

Интерфейс сайта «Рядом» с регистрацией, входом, JWT-interceptor и защищёнными маршрутом личного кабинета и административной панелью.

Запуск из директории `frontend`: `npm ci`, затем `npm start`. Бэкенд должен работать на http://127.0.0.1:5000; dev proxy указан в `proxy.conf.json`.

Полная инструкция, запуск PostgreSQL, создание Admin и тесты: [`../README.md`](../README.md).
