# Лабораторная работа №3. Бэкенд сайта «Рядом»

Бэкенд и тесты написаны на C# (.NET 10, ASP.NET Core Web API). Клиент на Angular 20 взят из второй лабораторной (коммит `17386a3`). Данные опросников, специалистов, слотов, истории и записей клиент получает через `/api`. Баллы вычисляются на сервере.

## Локальный запуск

Понадобятся **.NET 10 SDK** и **Node.js 24 LTS**. Открой два терминала в папке `lab3`.

**Первый терминал — бэкенд**

```powershell
dotnet run --project backend/Ryadom.Api --urls http://127.0.0.1:5000
```

**Второй терминал — Angular**

```powershell
cd frontend
npm.cmd ci
npm.cmd start
```

На macOS и Linux используй `npm` вместо `npm.cmd`. Сайт доступен на <http://localhost:4200>. Angular CLI перенаправляет запросы `/api/**` на порт 5000 по настройке в `frontend/proxy.conf.json`. Внешние фотографии и шрифты загружаются при наличии доступа к их источникам.

**Автоматические проверки из папки `lab3`**

```powershell
dotnet test Ryadom.sln
cd frontend
npm.cmd run build
```

Тесты xUnit проверяют доменные правила и HTTP-контракт ASP.NET Core через `WebApplicationFactory`. Отдельно проверяются конкурентная попытка занять один слот, отсутствие доступа к записи по чужому идентификатору посетителя, пагинация, неверные данные и HTTP-статусы.

## Как показать работу

1. На главной нажми «Пройти экспресс-тест», ответь на четыре вопроса и нажми «Получить результат». Сервер рассчитает баллы и создаст запись в истории.
2. В карточке психолога нажми «Записаться». Кнопка «Ещё время» загружает следующую страницу слотов. Выбери время, подтверди и открой «Мои консультации».
3. В личном кабинете перенеси созданную запись, затем отмени её. Старый слот снова появится в списке свободных.
4. Во вкладке Network в браузере можно показать `GET`, `POST`, `PUT` и `DELETE`. После удаления результат или запись исчезает из перечня.

Сервер хранит записи и результаты в памяти до перезапуска. Браузер сохраняет только случайный `X-Visitor-Id`, чтобы получить свою историю после обновления страницы. Это учебное разделение данных по посетителям. Профили специалистов и слоты демонстрационные, а баллы опросников рассчитаны по упрощённой формуле.

## DDD и структура

| Проект | Ответственность |
|---|---|
| `Ryadom.Domain` | Опросник, результат, специалист, слот, запись. Проверка полноты ответов, вычисление баллов, правила записи и переноса. |
| `Ryadom.Application` | Сценарии каталога, результатов и бронирования. Контракты репозиториев, получение времени, вызов доменных методов. |
| `Ryadom.Infrastructure` | Реализации контрактов в памяти, учебные данные, взаимоисключающий доступ при занятии слота. |
| `Ryadom.Api` | CRUD-действия контроллеров. Привязка и проверка входных данных, вызов приложения, преобразование ошибок в HTTP-ответы. |
| `Ryadom.Tests` | Модульные тесты Domain и интеграционные тесты API. |
| `frontend/` | Angular 20 и HTTP-клиент. Обработка состояний загрузки и ошибок, показ страниц данных. |

## Контракт API

Все списки принимают `page` (от 1 до 100 000) и `pageSize` (от 1 до 50). По умолчанию используются `1` и `12`. Ответ содержит `items`, `page`, `pageSize`, `total` и `hasNext`. Списки опросников возвращают карточки, вопросы загружаются по ID.

| HTTP-метод и маршрут | Данные и успешный ответ |
|---|---|
| `GET /api/assessments` | Страница опросников, `200`. Параметр `includeExpress=true` добавляет экспресс-тест. |
| `GET /api/assessments/{id}` | Вопросы и варианты ответов, `200`. |
| `GET /api/specialists` | Страница специалистов, `200`. |
| `GET /api/specialists/{id}` | Карточка специалиста, `200`. |
| `GET /api/specialists/{id}/slots` | Страница свободных будущих слотов, `200`. |
| `GET /api/results`, `GET /api/results/{id}` | История или один результат, `200`. |
| `POST /api/results` | `{ "assessmentId": "express", "answers": [0, 1, 2, 3] }`, `201` с `Location`. |
| `DELETE /api/results/{id}` | Удаление результата, `204`. |
| `GET /api/bookings`, `GET /api/bookings/{id}` | Записи или одна запись, `200`. |
| `POST /api/bookings` | `{ "specialistId": "anna", "slotId": "…" }`, `201` с `Location`. |
| `PUT /api/bookings/{id}` | `{ "slotId": "…" }`, `200` с обновлённой записью. |
| `DELETE /api/bookings/{id}` | Отмена записи, `204`. |

Для `/api/results` и `/api/bookings` передай заголовок `X-Visitor-Id` с непустым UUID. Angular делает это автоматически. Пример проверки из PowerShell при запущенном API:

```powershell
$headers = @{ 'X-Visitor-Id' = [guid]::NewGuid().ToString() }
$body = @{ assessmentId = 'express'; answers = @(0, 1, 2, 3) } | ConvertTo-Json
Invoke-RestMethod http://127.0.0.1:5000/api/results -Method Post -Headers $headers -Body $body -ContentType 'application/json'
Invoke-RestMethod 'http://127.0.0.1:5000/api/results?page=1&pageSize=1' -Headers $headers
```

Ошибки возвращаются в формате Problem Details. `400` используется для неверных JSON, параметров, идентификаторов и заголовков. `404` — для отсутствующего ресурса. `409` — для занятого слота или конкурентного изменения. `422` — для нарушения доменного правила, например если число ответов не совпало с числом вопросов.
